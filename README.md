# Chat Backend

Initial project setup for Chat Backend assessment.

## Prerequisites
- Node.js (v18+)
- PostgreSQL
- Firebase Project

## Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file from `.env.example`.
4. Fill in the required environment variables.

## Running the Project
- Development: `npm run dev`
- Build: `npm run build`
- Start: `npm run start`
